# Symphony Website — UI kit

High-fidelity recreation of the symphony.is marketing site, composed from the
design-system components (`window.Symphony`).

**Screens** (in `index.html`, switchable via the top nav):
- **Home** — announcement bar, header, aurora hero ("We are Symphony"), partner tiles.
- **Who we are** — "Our people and culture" glass Vision/Mission panels + "Global footprint" map section.
- **Let's work together** — outcome StatCards + "Get started" contact form.
- **Case study** — "One auditable, AI-ready tax platform" detail hero with category tags + image.

Source: screenshots of symphony.is (no codebase/Figma provided). Imagery uses
striped placeholders — drop in real photography/partner logos when available.

Files: `Hero.jsx`, `Culture.jsx`, `Contact.jsx`, `CaseStudy.jsx` are the factored
source; `index.html` is the interactive click-through.
