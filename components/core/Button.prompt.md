Primary action button — solid indigo glow for the main CTA, glass/ghost/outline for lower emphasis. Use the arrow for forward navigation ("Read the case study", "Get started").

```jsx
<Button variant="primary" size="lg" arrow>Read the case study</Button>
<Button variant="secondary">Learn more</Button>
```

Variants: `primary` (default, indigo gradient + glow), `secondary` (glass), `ghost`, `outline`. Sizes: `sm | md | lg`. Props: `arrow`, `shape="pill"`, `disabled`.
