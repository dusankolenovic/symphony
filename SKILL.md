Read the `readme.md` file within this skill, and explore the other available files
(`styles.css` + `tokens/`, `components/`, `guidelines/`, `ui_kits/website/`).

Symphony is a dark-first brand: blue-tinted near-black canvas, a signature spectrum
"aurora" gradient, periwinkle-indigo primary (`#6D5DF6`) with the logo purple
`#6050A0`, **Poppins** for all type (SemiBold/Bold headlines, Regular body,
ALL-CAPS eyebrow labels), glass cards, soft-large radii, thin line icons,
sentence-case copy, no emoji. The official wordmark lives at
`assets/symphony-logo.png`.

If creating visual artifacts (slides, mocks, throwaway prototypes), copy assets out
and create static HTML files linking `styles.css` for the user to view. If working
on production code, copy assets and read the rules here to become an expert in
designing with this brand.

If the user invokes this skill without other guidance, ask what they want to build,
ask a few clarifying questions, and act as an expert Symphony designer who outputs
HTML artifacts or production code depending on the need.
